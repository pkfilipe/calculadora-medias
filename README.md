# 📊 Calculadora de Médias Pro

Uma aplicação web moderna, responsiva e intuitiva para cálculo de médias escolares e acadêmicas, desenvolvida com **HTML5, CSS3 e JavaScript Vanilla**.

## 🚀 Funcionalidades

- 📈 **Média Simples e Ponderada**: Escolha entre média aritmética ou atribua pesos individuais para cada avaliação.
- 🎯 **Meta Configurável**: Defina a média mínima de corte para aprovação e nota de recuperação.
- 📏 **Escalas Flexíveis**: Suporte para notas de **0 a 10** ou **0 a 100**.
- ➕ **Dinâmico**: Adicione ou remova quantas notas e matérias/provas desejar.
- 🌗 **Modo Escuro / Claro**: Interface adaptável com alternância de temas.
- 📊 **Feedback Visual Imediato**:
  - Destaque colorido de aprovação, recuperação e reprovação.
  - Barra de progresso comparativa em relação à meta.
  - Indicadores de maior nota, menor nota e margem de pontos.
- 📋 **Exportação Rápida**: Copie um resumo formatado das notas diretamente para a área de transferência.
- 💾 **Persistência Local**: Salva automaticamente seus dados no navegador (`localStorage`).
