# 📊 Calculadora de Médias Simples

Projeto simples e direto para calcular a média de 3 notas, desenvolvido com **HTML, CSS e JavaScript**.

🔗 **Demonstração Online:** [https://pkfilipe.github.io/calculadora-medias/](https://pkfilipe.github.io/calculadora-medias/)

---

## 📌 Funcionalidades

- Campo para **1ª Nota**
- Campo para **2ª Nota**
- Campo para **3ª Nota**
- Botão **Calcular Média** (mostra a média e se o aluno está Aprovado, em Recuperação ou Reprovado)
- Botão **Limpar** para resetar os campos

---

## 📁 Estrutura de Arquivos

```
calculadora-medias/
├── index.html   # Estrutura dos 3 campos de notas e botões
├── styles.css   # Estilização limpa e centralizada
└── script.js    # Cálculo simples da média aritmética
```

---

## 💻 Como Executar

Basta abrir o arquivo `index.html` em qualquer navegador ou no VS Code.
